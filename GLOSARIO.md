# Glosario

1. **PATH** - Es la direccion que le indica a la computadora dónde buscar los archivos.
2. **dist** - Es la carpeta donde se guarda el código final después de que la computadora lo procesa.
3. **class** - Es como un molde para fabricar objetos que comparten las mismas caracteriticas.
4. **npm** - Node Package Manager, es una biblioteca de codigo abierto.
5. **npx** - Es como un botón para ejecutar herramientas de esa biblioteca, sin tener que instalarlas permanentemente.
6. **strict** - Se usa para que revise el código que no deje pasar ningun minimo error.
7. **extends (interface)** - Sirve para heredar, a una estructura base le podemos sumar nuevas propiedad sin tener que escribir todo denuevo.
8. **Tipo literal** - Es cuando una variable no acepta cualquier valor, solo uno exacto.
9. **include** - Es la lista de instrucciones que le dice a TypeScript que archivos traducir.
10. **node** - Programa que permite a la computadora entender y ejecutar código de programación fuera del navegador.
